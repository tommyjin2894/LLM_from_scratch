## 🍼 유치원 버전: 어텐션은 "교실에서 누구 말을 들을까"야

문장 속 단어들이 교실에 앉아 있는 학생들이라고 해봐.
**"그 동물은 길을 건너지 못했다. 왜냐하면 그것은 너무 피곤했기 때문이다."**
"그것"이라는 학생은 궁금해: *나는 누구를 가리키지?*
그래서 교실의 모든 학생에게 **귀 기울이는 정도를 다르게** 정해 — "동물"에게 80%, "길"에게 5%...
이게 **어텐션(주의집중)**이야. 모든 단어가 동시에, 서로에게, 이걸 해.

**도서관 비유로 더 정확하게 (Q, K, V):**
- 내가 찾는 것을 적은 쪽지 = **Query** ("나는 '그것'인데, 앞에 나온 동물 명사를 찾아")
- 책마다 등에 붙은 라벨 = **Key** ("나는 동물 명사야" / "나는 장소야")
- 책의 실제 내용 = **Value**
- 내 쪽지(Q)와 라벨(K)이 잘 맞는 책일수록 그 내용(V)을 많이 빌려와서 섞어.
- **"잘 맞는다" = 내적이 크다** (01에서 배운 닮음 점수!)

그리고 트랜스포머의 진짜 혁명은: 이 과정에 "순서대로"가 없어서
**문장 전체를 한 방에 병렬로** 계산해 → GPU 알바 1만 명이 전원 풀가동 → 거대 모델 학습 가능.

## 🧠 제대로 배우기 — GPT 한 채를 바닥부터 짓기

### 0. 전체 설계도 (디코더-온리, GPT 스타일 — 2026년 LLM의 표준)

```
토큰 ID들 (B, T)
  │ ① 토큰 임베딩 (+ 위치 정보)              (B, T, d)
  ▼
┌─ 트랜스포머 블록 × N층 ──────────────────┐
│  x = x + Attention(Norm(x))   ← ② ③ ④   │  (pre-LN + 잔차)
│  x = x + FFN(Norm(x))         ← ⑤        │
└──────────────────────────────────────────┘
  │ ⑥ 최종 Norm → LM head (d → vocab)
  ▼
다음 토큰 로짓 (B, T, vocab) → 소프트맥스 → 샘플링
```

### ① 임베딩
- `nn.Embedding(vocab, d)`: 토큰 ID → 벡터 (lookup). 05에서 배운 의미 지도
- **weight tying**: 입력 임베딩과 출력 LM head가 가중치 공유 (GPT-2 전통, 파라미터 절약)

### ② 셀프 어텐션 — 수식을 한 줄씩
입력 X (T×d)에서 세 개의 투영:
```
Q = XW_Q,  K = XW_K,  V = XW_V          # 쪽지, 라벨, 내용 만들기
scores = QKᵀ / √d_k                      # (T×T) 모든 쌍의 닮음 점수
scores += causal_mask                    # 미래는 -∞ (컨닝 금지)
A = softmax(scores, dim=-1)              # 행마다 "누구 말을 얼마나" 확률
out = AV                                 # 가중 평균으로 내용 섞기
```
- **왜 √d_k로 나누나**: d가 크면 내적의 분산이 d에 비례해 커짐 → 소프트맥스가 한 점에 몰림(포화) → 그래디언트 소멸. 분산을 1로 되돌리는 보정. (직접 실험해볼 것 — 실습 2)
- **causal mask**: 위치 t는 1..t만 봄. 학습 시 T개 위치 전부가 "각자의 다음 토큰 예측 문제"가 됨 → 한 문장에서 T개의 학습 신호 (효율의 비밀)
- 어텐션은 **시퀀스 간 정보 이동**, 파라미터는 투영 행렬뿐. (T×T) 계산 = **컨텍스트 길이의 제곱 비용** — 장문맥이 비싼 이유

### ③ 멀티헤드 어텐션
- d를 h개 머리로 쪼갬 (예: 4096 = 32헤드 × 128차원). 각 머리가 **다른 안경**으로 봄
  (어떤 머리는 문법, 어떤 머리는 지시어, 어떤 머리는 "직전 단어 복사"...)
- 구현은 reshape 마술: `(B,T,d) → (B,T,h,d/h) → (B,h,T,d/h)` — 02에서 연습한 그것
- 결과를 concat 후 출력 투영 W_O

### ④ 위치 정보 — "순서"를 잃어버린 대가
어텐션은 집합 연산이라 순서를 모름 → 위치를 주입해야 함. 역사:
1. **사인/코사인** (2017 원조): 고정 파형 더하기
2. **학습 임베딩** (GPT-2): 위치마다 벡터 학습
3. **RoPE** (2021, 현 표준): 🍼 *단어마다 시계바늘을 위치만큼 돌려놓기.* Q와 K를 위치 비례 각도로 회전 → 내적이 **상대 위치만**에 의존하게 됨. 외삽·장문맥에 유리
4. RoPE 주파수(θ) 조정·**YaRN** 등으로 컨텍스트 연장 (8K로 학습 → 128K 서비스의 비밀, Phase 07)
5. ALiBi(거리 벌점), **NoPE**(위치 없이도 됨?) 등 변종 — 개념만

### ⑤ FFN (피드포워드) — 모은 정보 소화하기
- 🍼 어텐션이 "친구들 이야기 모아오기"라면 FFN은 "혼자 곱씹어 소화하기" (토큰별 독립)
- 고전: `Linear(d→4d) → GELU → Linear(4d→d)`
- **현대 표준 SwiGLU**: `(SiLU(xW_gate) ⊙ xW_up)W_down` — 게이트가 정보 흐름을 조절. Llama/Qwen/DeepSeek 전부 이것
- 파라미터의 **약 2/3가 FFN에** 있음. "지식 저장소"로 여겨짐 (수술적 지식편집 연구도 FFN을 건드림)

### ⑥ 잔차 연결 + 정규화
- **잔차(residual)**: x + f(x). 🍼 *고속도로 본선은 그대로 두고 옆길에서 조금씩 더하기.* 그래디언트가 고속도로로 직통 → 100층도 학습 가능
- **pre-LN** (Norm을 블록 안 입구에): post-LN(원논문)보다 안정 → 현대 표준. + RMSNorm(04)
- 최근 안정화 트릭: **QK-Norm**(어텐션 폭주 방지, Gemma/Qwen3 채택), z-loss — Phase 07에서

### ⑦ 학습과 생성
- 손실: 모든 위치의 다음 토큰 크로스 엔트로피 평균 (01의 삼위일체!)
- 생성: 한 토큰 뽑고 → 뒤에 붙이고 → 다시 forward (자기회귀 루프)
- **KV 캐시**: 🍼 *이미 읽은 책의 라벨(K)과 내용(V)을 포스트잇으로 붙여둠* — 매번 다시 계산 안 함. 생성 속도의 생명줄, 그리고 메모리 먹는 하마 (Phase 10에서 크기 계산)

### ⑧ 가계도 — 왜 다들 디코더-온리인가
| 구조 | 대표 | 방식 | 운명 |
|---|---|---|---|
| 인코더-온리 | BERT (2018) | 빈칸 채우기(MLM), 양방향 | 이해 태스크 강자였으나 생성 불가 → 임베딩 모델로 생존 (RAG에서 재회) |
| 인코더-디코더 | T5, 원조 트랜스포머 | 번역형 | 일부 생존 (Whisper 등) |
| **디코더-온리** | **GPT 계열 전부** | 다음 토큰 예측 | **승자.** 이유: 학습 신호 효율 + 모든 태스크를 "이어쓰기"로 통일 + 스케일링 단순 |

## 🔬 2026 어텐션의 진화 (신모델 테크리포트 읽기용 치트시트)

| 기법 | 아이디어 | 누가 씀 |
|---|---|---|
| **MQA/GQA** | K,V 머리를 여러 Q가 공유 (KV캐시 ↓) | Llama 2-3, Qwen, 거의 전부 |
| **MLA** | K,V를 저차원 잠재벡터로 압축 저장 (🍼 책 대신 요약본 보관) — KV캐시 ~90%↓ | DeepSeek V2/V3/V4 |
| 슬라이딩 윈도 | 가까운 것만 풀 어텐션 | Mistral, Gemma (하이브리드 층) |
| **NSA/DSA** (네이티브 희소) | 학습 때부터 희소 어텐션 (압축+선택+윈도) | DeepSeek V3.2+ — 장문맥 비용 혁명 |
| 선형/하이브리드 | 어텐션을 RNN형 상태로 (Mamba, GDN) + 풀어텐션 소수 혼합 | Qwen3-Next, Kimi Linear 등 (Phase 10) |
| 1M+ 컨텍스트 | RoPE 스케일링 + 위 기법들의 합작 | Llama 4 (10M), DeepSeek V4 (1M), Gemini |

## 🧪 실습 과제
1. **[필수]** 단일 헤드 어텐션을 NumPy로 (소프트맥스 포함, 마스크 포함) — 3×3 장난감 예제 손 검산
2. **[필수]** √d_k 실험: d=512에서 스케일링 유/무로 소프트맥스 출력 분포와 그래디언트 크기 비교
3. **[필수: M2]** Karpathy 따라 GPT 구현 → 셰익스피어 학습 → 그럴듯한 가짜 셰익스피어 생성. 그 다음 **한국어 데이터로 교체** (예: 옛 소설, 가사) — 토크나이저는 05에서 만든 내 BPE 사용
4. **[필수]** **파라미터 수 손 계산**: Llama-2-7B (d=4096, 32층, 32헤드, FFN 11008, vocab 32000)가 정말 ~6.7B인지 계산기로 검증. 임베딩/어텐션/FFN 비율 파이차트
5. **[심화]** 내 GPT에 RoPE 직접 구현해서 학습 임베딩과 손실 비교
6. **[심화]** 어텐션 맵 시각화: 특정 헤드가 "직전 토큰"만 보는지, 문장 시작만 보는지 관찰 (해석가능성 맛보기, Phase 13 예고)
7. **[심화]** GQA로 바꿔보기: KV 헤드 32→8, 품질/메모리 변화 측정
