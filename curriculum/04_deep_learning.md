### 🍼 유치원 버전

**신경망 = 레고 블록 쌓기야.**
한 층은 "행렬곱(변신 기계) + 구부리기(활성화 함수)". 이걸 여러 층 쌓으면
직선밖에 못 긋던 기계가 **아무리 구불구불한 경계선도** 그릴 수 있게 돼.
(구부리기가 없으면? 변신 기계 100개 = 변신 기계 1개. 선형×선형=선형이라서. 그래서 활성화 함수가 필수!)

**역전파 = "누구 탓이야?" 게임이야.**
시험을 틀렸어. 마지막 층부터 거꾸로 따져 들어가:
"네가 0.3만큼 잘못했고 → 그건 그 앞 녀석이 0.1 잘못 준 탓이고 → ..."
연쇄법칙(01)으로 **모든 다이얼의 책임을 한 번의 역방향 통과로 전부 계산**해.
70억 개 다이얼이라도 순전파 1번 + 역전파 1번이면 끝. 이 효율성이 딥러닝을 가능하게 했어.

## 🧠 제대로 배우기

### 1. 역전파 — 이 단계의 심장 ❤️
- 계산 그래프: 모든 계산을 노드와 엣지로. 순전파는 왼→오, 역전파는 오→왼
- 각 노드는 **로컬 그래디언트**만 알면 됨. 전역 그래디언트 = 로컬들의 곱 (연쇄법칙)
- `+`는 그래디언트 분배기, `×`는 교환기, `max`는 라우터 — 게이트별 직관 (CS231n)
- **반드시 할 것**: Karpathy **micrograd** 영상(2.5h)을 보고, 안 보고 다시 짜기. 100줄짜리 autograd 엔진을 만들면 PyTorch의 `loss.backward()`가 마법이 아니게 됨

### 2. 활성화 함수의 역사 (= LLM까지의 진화)
sigmoid (기울기 소실로 몰락) → tanh → **ReLU** (2012 혁명: 음수는 0, 단순함의 승리)
→ **GELU** (GPT-2/BERT: 부드러운 ReLU) → **SiLU/Swish** → **SwiGLU** (게이트 추가; Llama·Qwen·DeepSeek 등 현대 LLM 표준, Phase 06에서 구현)

### 3. 최적화 — 다이얼 돌리기의 기술
| 옵티마이저 | 아이디어 | 비고 |
|---|---|---|
| SGD | 그냥 기울기 방향으로 | 기준점 |
| 모멘텀 | 관성 추가 (공 굴리기) | 골짜기 진동 줄임 |
| Adam | 방향(1차)+크기(2차) 적응 | 2014–현재 기본값 |
| **AdamW** | weight decay를 올바르게 분리 | **LLM 사전학습 표준** |
| **Muon** | 2차원 가중치에 직교화 업데이트 (2024) | modded-nanogpt 스피드런 → Kimi K2(1T)가 채택. 차세대 후보 |
- **학습률 스케줄**: warmup(초반 천천히) + cosine decay — LLM 학습의 표준 곡선. WSD 스케줄도 등장
- **그래디언트 클리핑**: 폭주 방지 (norm 1.0) — 사전학습 안정성 필수품

### 4. 정규화(Normalization) — 층 사이 신호 교통정리
- **BatchNorm**: 배치 방향 통계로 정규화. CNN 시대 왕. 그러나 배치/시퀀스 의존성 때문에 LLM 부적합
- **LayerNorm**: 각 토큰 벡터를 자기 자신 안에서 정규화 → 트랜스포머 원조
- **RMSNorm**: LayerNorm에서 평균빼기 생략, 스케일만 — 더 싸고 같은 효과. **현대 LLM 표준** (Llama 이후 사실상 전부)
- 왜 필요? 깊은 망에서 신호 분포가 층마다 출렁이면 학습 불안정 → 각 층 입구에서 리셋

### 5. 규제와 초기화
- 드롭아웃: 훈련 때 무작위로 뉴런 끄기 (의존 못 하게) — 단, **현대 LLM 사전학습에선 거의 안 씀** (데이터가 무한해서 과적합 걱정이 다름)
- weight decay: 다이얼이 너무 커지는 것 벌점
- 초기화: Xavier/He — 분산을 층 깊이에 맞게. 잘못하면 신호 폭발/소멸 (Karpathy 영상에서 손으로 체험)

### 6. (가볍게) CNN과 RNN
- CNN: 이미지의 지역 패턴 감지기. ViT(Phase 11) 이해에 패치 개념만 필요
- RNN: 05에서 역사적 맥락으로 다룸. 여기서는 "순서대로 처리하는 망이 있었다" 정도만
