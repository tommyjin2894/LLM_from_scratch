# 13. 평가, 안전, 해석가능성 — 이 기계를 믿어도 되나?

> **기간**: 3–4주 | **선행**: 08, 09, 12 | **산출물**: lm-eval 직접 실행 + SAE 피처 탐험 리포트
>
> "측정할 수 없으면 개선할 수 없다" — 그런데 LLM 측정은 생각보다 훨씬 어렵고,
> 이 어려움 자체가 거대한 연구 분야입니다. 안전·해석은 2026년 가장 채용 수요가 많은 연구 분야이기도 합니다.

### 🍼 유치원 버전

- **벤치마크** = 모의고사. 그런데 문제가 둘 있어:
  ① 기출문제가 교과서(학습 데이터)에 섞여 들어가 (**오염**) — 외운 건지 아는 건지 구분 불가
  ② 시험 잘 보는 기술만 늘 수도 있어 (**굿하트**) — 점수는 높은데 실제론 별로
- **해석가능성** = 뇌 MRI야. 다이얼 700억 개 속에서 "골든게이트 다리 뉴런", "아첨 뉴런"을 찾아내는 일.
  찾으면? **다이얼을 직접 돌려서** 성격을 바꿀 수도 있어 (실제로 Anthropic이 "골든게이트 클로드"로 시연)
- **정렬 문제** = 램프의 지니. 소원을 빌면 **말 그대로** 들어줘서 망해. "행복하게 해줘" → 뇌에 전극.
  우리가 원하는 건 "말한 것"이 아니라 "의도한 것"인데, 그걸 어떻게 가르치지?

## 🧠 제대로 배우기

### 1. 평가 — 생각보다 어려운 과학
**벤치마크 지도 (2026, 포화된 것 → 살아있는 것):**
| 영역 | 은퇴/포화 | 현역 |
|---|---|---|
| 지식 | MMLU | MMLU-Pro, **GPQA Diamond** (박사급 과학) |
| 수학 | GSM8K, MATH | AIME류, **FrontierMath**, IMO급 |
| 코딩 | HumanEval | **SWE-bench Verified/Pro**, Terminal-Bench, LiveCodeBench |
| 에이전트 | — | OSWorld, GAIA, τ-bench, 장기과제(METR 시간 지평) |
| 종합 | — | **HLE**(Humanity's Last Exam), **ARC-AGI-2**(비용 축 포함) |
| 선호 | — | LMArena (Elo, 사람 블라인드 투표 — 단 "아부 편향" 논쟁) |

**방법론의 함정들 (박사 기본기):**
- **오염**: 테스트셋이 사전학습 데이터에 유출 → n-gram/임베딩 오염 검사, 비공개 홀드아웃, 출제일 이후 데이터(LiveBench류)
- 프롬프트/포맷 민감성: 선택지 순서만 바꿔도 점수 출렁 → 표준 하니스(lm-eval-harness) 필수
- **LLM-as-judge**: 싸고 빠르지만 — 자기 답 선호, 길이 편향, 아첨 편향. 보정 기법과 한계
- 통계: 점수 차이의 유의성 (n=100 벤치에서 2%p는 노이즈일 수 있음) — 신뢰구간 습관
- 능력(capability) vs 성향(propensity) 구분, pass@k vs pass^k

### 2. 안전 — 공격과 방어
- **탈옥(jailbreak)**: 역할극, 인코딩, 다단계 설득, GCG(그래디언트로 만든 접미사), 다국어 우회... 창과 방패의 역사
- **프롬프트 인젝션** (12에서): 데이터 속 지시. 에이전트 시대의 1순위 보안 문제 — "지시/데이터 권한 분리"가 근본적으로 미해결
- 학습 데이터 중독, 백도어 (개념 수준)
- 방어 스택: 안전 학습(RLHF/CAI) + 분류기 가드레일 + 시스템 수준 격리(샌드박스, 권한) — "모델만으로 못 막는다"
- 거버넌스 감각: 프런티어 랩의 안전 프레임워크(RSP류), 위험 평가(생물·사이버·자율성) — 뉴스를 읽는 눈

### 3. 해석가능성 (Interpretability) — 뇌과학
- **기초 발견들**: induction heads(문맥 내 복사 회로 — in-context learning의 메커니즘 후보), 어텐션 헤드 역할 분화 (06 실습에서 봤던 것!)
- **중첩(superposition)**: 뉴런 수보다 많은 개념을 욱여넣어 표현 → 뉴런 하나 ≠ 개념 하나 (다의미 뉴런)
- **SAE (Sparse Autoencoder)**: 활성값을 희소한 "피처"로 분해 → 단일의미 피처 발견 (Anthropic 2024 "Scaling Monosemanticity" — 골든게이트 피처, 기만 피처...)
- **회로 추적(circuit tracing)**: 피처들의 연결 그래프로 "모델이 이 답을 낸 경로" 추적 (Anthropic 2025 "Biology of an LLM" — 시 쓰기에서 **미리 계획**하는 증거, 암산 회로 등)
- **CoT faithfulness**: 모델이 쓴 풀이 ≠ 실제 내부 계산일 수 있음 (09의 복선 회수) — 추론 모델 감시 가능성 문제
- 응용: 피처 스티어링(다이얼 돌리기), 거짓말 탐지 프로브, 모델 디핑 — 막 열리는 분야

### 4. 정렬 이론 (큰 그림)
- RLHF의 한계: 인간이 평가 못 하는 수준의 출력은? → **scalable oversight** (토론, 재귀적 보상모델링, weak-to-strong)
- 기만적 정렬(훈련 중에만 착한 척) 우려와 실증 연구들 (sleeper agents, alignment faking)
- 입장 지형 파악: 낙관-비관 스펙트럼의 주요 논자들 — 한쪽 결론을 외우지 말고 **논증 구조**를 배울 것
