## 1. 선형대수 — LLM의 모든 것은 행렬곱이다

### 🍼 유치원 버전
- **벡터** = 숫자 목록 = 지도 위 화살표. "고양이"라는 단어도 LLM 안에서는 숫자 4096개짜리 화살표야.
- **행렬** = 숫자 변신 기계. 화살표를 넣으면 돌리고 늘려서 다른 화살표로 바꿔줘.
- **내적(dot product)** = 두 화살표가 얼마나 같은 방향인지 재는 점수. **"닮음 점수"**.
  → 나중에 배울 어텐션의 심장이 바로 이 닮음 점수!

### 🧠 제대로 배우기
| 주제 | 꼭 알아야 할 것 | LLM 어디에 나옴? |
|---|---|---|
| 벡터, 내적, 노름 | 내적 = \|a\|\|b\|cosθ, 코사인 유사도 | 어텐션 점수, 임베딩 검색(RAG) |
| 행렬곱 | (m×k)(k×n)=(m×n), 계산량 O(mkn), **결합법칙** | 모델 전체가 행렬곱 덩어리. FLOPs 계산 |
| 선형변환 | 행렬 = 공간을 회전/늘림하는 함수 | 각 레이어 = 표현 공간의 변환 |
| 랭크, 저랭크 근사 | rank(AB) ≤ min(rank) | **LoRA**가 통하는 이유 (ΔW ≈ BA, 저랭크) |
| 고유값/SVD | 개념 수준 (계산 숙달 불필요) | 임베딩 분석, 압축 |
| 텐서 | 행렬의 n차원 일반화, shape 다루기 | 코드의 모든 줄: (batch, seq, d_model) |

**감 잡기**: 7B 모델 = 70억 개의 숫자가 들어있는 행렬 수백 개. 한 토큰을 생성할 때마다 그 행렬들과 곱셈을 합니다. 그래서 GPU(행렬곱 전용 기계)가 필요한 거예요.

## 2. 미적분 — "다이얼을 어느 쪽으로 돌릴까"의 수학

### 🍼 유치원 버전
안개 낀 산에서 내려가야 해. 멀리는 안 보여. 어떡하지?
→ **발바닥으로 기울기를 느끼고, 가장 가파른 내리막 쪽으로 한 걸음.** 이걸 반복.
- 발바닥 기울기 = **그래디언트(gradient)**
- 한 걸음 크기 = **학습률(learning rate)** (너무 크면 계곡을 건너뛰고, 너무 작으면 평생 못 내려감)
- 산의 높이 = **손실(loss)** = "얼마나 틀렸나"

### 🧠 제대로 배우기
| 주제 | 꼭 알아야 할 것 | LLM 어디에 나옴? |
|---|---|---|
| 미분의 정의 | 순간 변화율, 접선 기울기 | 모든 것 |
| 편미분, 그래디언트 | ∂f/∂x: 다른 변수 고정하고 하나만 | 파라미터 70억 개 각각의 "책임 크기" |
| **연쇄법칙(chain rule)** | dz/dx = dz/dy · dy/dx | **역전파 그 자체.** 이 커리큘럼에서 가장 중요한 수식 1개를 꼽으라면 이것 |
| 야코비안 | 벡터→벡터 함수의 미분 (개념) | 레이어 단위 역전파 |
| 볼록/비볼록 | 신경망 손실은 비볼록 → 국소최소 걱정? (고차원에선 안장점이 더 문제) | 최적화 이해 |

**손 운동 (필수)**: f(x) = (wx + b - y)² 를 w, b로 미분해보기. 이게 되면 신경망 역전파의 80%는 끝.

## 3. 확률·통계 — LLM은 확률 기계다

### 🍼 유치원 버전
LLM의 진짜 출력은 단어가 아니라 **"다음에 올 수 있는 모든 레고 블록의 당첨 확률표"**야.
"아침에 이를 ___" 다음에: 닦았다(70%), 쑤셨다(5%), 바나나(0.0001%)...
그 표에서 **제비뽑기**를 해서 하나를 골라. 온도를 올리면 이상한 블록도 가끔 뽑혀 (모험심↑).

### 🧠 제대로 배우기
| 주제 | 꼭 알아야 할 것 | LLM 어디에 나옴? |
|---|---|---|
| 확률분포, 조건부확률 | P(다음토큰 \| 지금까지 문맥) | **언어모델의 정의가 이것**: P(x_t \| x_<t) |
| 연쇄법칙(확률) | P(문장) = ∏ P(x_t\|x_<t) | 자기회귀(autoregressive) 생성 |
| 기댓값, 분산 | E[X], Var[X] | 손실 = 기댓값, 초기화 = 분산 조절 |
| 베이즈 정리 | 사후 ∝ 우도 × 사전 | 평가, 베이지안 관점 |
| **최대우도추정(MLE)** | "이 데이터가 나올 확률을 최대로 하는 파라미터" | **사전학습 = 인터넷 텍스트의 MLE** |
| 소프트맥스 | 점수 → 확률 변환: e^z_i / Σe^z_j | 어텐션 가중치, 출력 확률 둘 다 |
| 샘플링 | temperature, top-k, top-p(nucleus) | 생성 품질 조절의 전부 |

## 4. 정보이론 — 손실함수의 고향

### 🍼 유치원 버전
- **정보량** = 놀람의 크기. "내일 해가 뜬다"(놀람 0) vs "내일 눈이 온다, 6월에"(놀람 큼).
  자주 일어나는 일일수록 정보가 적어.
- **엔트로피** = 평균 놀람. 동전 던지기(반반)는 매번 놀라움이 있고, 찌그러진 동전(항상 앞면)은 안 놀라워.
- **퍼플렉시티(perplexity)** = LLM의 "헷갈림 지수". "다음 단어 후보를 평균 몇 개 사이에서 고민하나".
  좋은 모델일수록 낮음. GPT-2가 나쁜 모델이던 시절 PPL이 수십, 요즘 좋은 모델은 한 자릿수.

### 🧠 제대로 배우기
| 주제 | 수식 | LLM 어디에 나옴? |
|---|---|---|
| 자기정보량 | I(x) = -log p(x) | 토큰 하나의 "어려움" |
| 엔트로피 | H(p) = -Σ p log p | 데이터의 본질적 불확실성 |
| **크로스 엔트로피** | H(p,q) = -Σ p log q | **사전학습 손실함수가 정확히 이것.** 정답분포 p(원핫)와 모델분포 q의 차이 |
| KL 발산 | KL(p‖q) = Σ p log(p/q) | **RLHF의 고삐** ("원래 모델에서 너무 멀어지지 마"), 증류 |
| 퍼플렉시티 | PPL = exp(평균 크로스엔트로피) | 사전학습 모델의 표준 성적표 |

**연결 완성**: MLE 최대화 = 크로스 엔트로피 최소화 = "덜 놀라는 모델 만들기". 셋이 같은 말임을 유도해보기. 이게 되면 이 장 졸업.

## 🧪 실습 과제

1. **[필수]** NumPy만으로: 랜덤 행렬 A(3×4), B(4×2) 곱하기 → 손으로 검산
2. **[필수]** f(w,b) = (wx+b-y)² 의 ∂f/∂w, ∂f/∂b 손 유도 → 파이썬으로 수치미분과 비교 (`(f(w+h)-f(w-h))/2h`)
3. **[필수]** 소프트맥스 + 크로스엔트로피를 NumPy로 구현, 3클래스 장난감 예제로 손실 계산
4. **[심화]** "온도 T로 나눈 소프트맥스"가 T→0이면 argmax, T→∞이면 균등분포가 됨을 코드로 확인
5. **[심화]** 두 가우시안의 KL 발산 시각화 (이게 RLHF에서 모델이 도망가지 못하게 묶는 끈)
