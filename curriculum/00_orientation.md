## 🍼 다섯 살에게 설명하기

**Q. LLM(거대 언어 모델)이 뭐야?**

세상에 있는 글(책, 인터넷, 코드...)을 어마어마하게 많이 읽고,
**"다음에 올 말 맞히기" 게임**을 수조(兆) 번 연습한 기계야.

> "아침에 일어나서 이를 ___" → "닦았다"

이 게임을 정말 정말 잘하게 되면 신기한 일이 벌어져.
다음 말을 잘 맞히려면 문법도 알아야 하고, 상식도 알아야 하고,
수학 문제 답도 알아야 하거든. 그래서 "다음 말 맞히기"만 연습했는데
**어느새 말도 하고, 번역도 하고, 코딩도 하는 친구**가 된 거야.

**Q. 그 기계 안에는 뭐가 들어있어?**

엄청나게 많은 **다이얼(손잡이)**이 들어있어. 몇십억~몇조 개.
이걸 어려운 말로 **파라미터**라고 해.
처음엔 다이얼이 다 엉망으로 맞춰져 있어서 아무 말이나 해.
그런데 게임에서 틀릴 때마다 "어느 다이얼을 어느 쪽으로 돌리면 덜 틀릴까?"를 계산해서
**아주 조금씩** 돌려. 이걸 수조 번 반복하면 다이얼들이 점점 좋은 위치를 찾아가.
이게 **학습(training)**이야.

**Q. 글자를 어떻게 읽어?**

기계는 글자를 몰라. 숫자만 알아. 그래서 문장을 **레고 블록(토큰)**으로 쪼개고,
블록마다 번호를 붙여. "안녕하세요"가 [31552, 9821] 같은 숫자 목록이 되는 거야.

**Q. ChatGPT는 왜 말을 잘 들어?**

"다음 말 맞히기"만 배운 기계(=**베이스 모델**)는 사실 말을 잘 안 들어.
"파리의 수도가 어디야?"라고 물으면 "런던의 수도는 어디야? 베를린의 수도는 어디야?"
하고 **비슷한 질문을 계속 이어붙이기도** 해. 자동완성 기계니까.
그래서 3단계 교육을 더 시켜:

1. **학교 보내기 (사전학습)** — 세상 글 다 읽고 다음 말 맞히기 (지식 쌓기)
2. **예절 교육 (SFT)** — "질문엔 이렇게 답하는 거야" 모범답안 따라쓰기
3. **칭찬 스티커 (RLHF/RL)** — 좋은 대답엔 스티커, 나쁜 대답엔 엑스. 스티커 받는 쪽으로 다이얼 조정

**Q. 가끔 거짓말도 하던데?**

응, 그걸 **환각(hallucination)**이라고 해. 거짓말이라기보다는...
"그럴듯한 다음 말"을 만드는 기계라서, 모르는 것도 **자신만만하게 그럴듯하게 지어내는** 거야.
허풍쟁이 친구 같은 거지. 이걸 고치는 게 지금도 큰 숙제야.

## 🧠 전체 파이프라인 — 이 커리큘럼의 지도

ChatGPT 같은 모델이 만들어지는 전 과정. **각 화살표가 이 커리큘럼의 단계 하나**입니다.

```
인터넷 텍스트 수십조 토큰                                  [Phase 07: 데이터]
        │  토크나이저로 숫자화                              [Phase 05]
        ▼
┌─────────────────────────┐
│  사전학습 (Pretraining)    │  다음 토큰 예측, GPU 수천 장, 수개월   [Phase 07]
│  → 베이스 모델             │  아키텍처 = 트랜스포머              [Phase 06]
└─────────────────────────┘
        │  지시 따르기 교육 (SFT)                           [Phase 08]
        │  선호 학습 (RLHF / DPO)                          [Phase 08]
        │  검증가능 보상 RL → 생각하는 법 학습 (GRPO)          [Phase 09]
        ▼
┌─────────────────────────┐
│  채팅/추론 모델            │  ChatGPT, Claude, Gemini...
└─────────────────────────┘
        │  양자화·서빙 최적화                                [Phase 10]
        │  눈·귀 달기 (멀티모달)                             [Phase 11]
        │  손 달기 (도구·에이전트·RAG)                        [Phase 12]
        ▼
   제품 + 평가·안전·해석                                    [Phase 13]
```

이 그림을 **외우지 말고**, 14단계가 끝날 때마다 다시 보세요. 점점 해상도가 올라갑니다.

## ✏️ 미리 보는 핵심 용어 10개

| 용어 | 🍼 유치원 버전 | 어른 버전 |
|---|---|---|
| 토큰 | 말 레고 블록 | 텍스트의 최소 처리 단위 (서브워드) |
| 파라미터 | 뇌 속 다이얼 | 학습되는 가중치 행렬의 원소 |
| 사전학습 | 도서관 책 다 읽기 | 대규모 코퍼스로 다음 토큰 예측 학습 |
| 파인튜닝 | 신입사원 교육 | 사전학습된 모델을 특정 목적으로 추가 학습 |
| 인퍼런스(inference) | 시험 보기 | 학습된 모델로 출력을 생성하는 단계 |
| 리즈닝(reasoning) | 연습장에 풀이 쓰기 | 답 전에 긴 사고 과정(CoT)을 생성하는 것 |
| 컨텍스트 | 한 번에 기억하는 양 | 모델이 한 번에 처리하는 토큰 수 (윈도) |
| 환각 | 자신만만한 허풍 | 사실과 다른 내용을 유창하게 생성하는 현상 |
| 온도(temperature) | 모험심 다이얼 | 샘플링 분포의 뾰족함 조절 (0=안전, 높음=창의/위험) |
| 벤치마크 | 모의고사 | 모델 성능을 재는 표준 시험 (MMLU, SWE-bench...) |

> ⚠️ 한국어 함정: inference도 "추론", reasoning도 "추론"으로 번역됩니다. 완전히 다른 개념!
> 이 커리큘럼에서는 inference=**인퍼런스(응답 생성)**, reasoning=**리즈닝(사고)**으로 구분합니다.
