# 09. 추론(Reasoning) 모델 — 생각하는 시간을 사는 법

> **기간**: 3–4주 | **선행**: 08 (GRPO 필수) | **산출물**: **마일스톤 M5** — GRPO로 미니 추론모델
>
> 2024년 9월(o1)부터 지금까지 LLM 판도를 바꾼 단 하나의 흐름. 2026년 현재 모든 프런티어 모델이
> "생각하고 답하는" 모델이며, 연구비의 가장 큰 몫이 여기에 들어갑니다.

### 🍼 유치원 버전

수학 문제를 받았어. 두 가지 방법이 있어:
- **머릿속 암산으로 바로 답 말하기** — 옛날 모델. 어려운 문제는 틀려
- **연습장에 풀이를 차근차근 쓰고 답하기** — 추론 모델. "잠깐, 아까 거 틀렸네. 다시 해보자"도 가능!

신기한 발견 1: 모델한테 "차근차근 생각해봐(step by step)"라고만 해도 점수가 확 올라 (2022, CoT)
신기한 발견 2: 연습장을 **더 오래** 쓰게 할수록 더 잘 풀어 — 시험시간을 돈으로 살 수 있게 된 거야 (test-time compute)
신기한 발견 3: "풀이가 맞으면 칭찬"만 줬더니, 모델이 **스스로** 검산하고, 되돌아가고, "어? 잠깐만…" 하는 법을 발명했어 (R1-Zero의 "aha moment")

## 🧠 제대로 배우기

### 1. 프롬프팅 시대 (2022–2023) — 공짜 점심의 발견
- **CoT** (Wei et al. 2022): 풀이 예시를 보여주면 대형 모델만 점수 급등 — "창발" 논쟁의 진원지
- Zero-shot CoT: "Let's think step by step" 한 줄의 마법
- **Self-consistency**: 여러 번 풀게 하고 다수결 — test-time compute의 원시 형태
- ToT/탐색 계열: 가지치기하며 생각 — 비싸서 주류는 안 됐지만 아이디어는 생존
- 왜 통할까: 토큰 하나당 계산량은 고정 → 어려운 문제는 **토큰을 더 써서** 계산을 늘려야 함 (직렬 계산 깊이의 확장)

### 2. 학습 시대 (2024–) — 생각을 RL로 가르치기
- **o1** (OpenAI, 2024.9): 대규모 RL로 긴 CoT를 학습. 능력은 보였지만 레시피는 비공개
- **DeepSeek-R1** (2025.1): **레시피 전부 공개** — 이 분야의 로제타석. 반드시 정독:
  - **R1-Zero**: 베이스 모델(V3)에 SFT 없이 **순수 GRPO**(보상 = 정답 여부 + 형식)만 →
    추론 길이가 스스로 자라고, 자기검증·백트래킹이 **창발**. "aha moment"
  - **R1**: cold-start SFT(소량 고품질 CoT) → 추론 RL → 거부샘플링으로 SFT 데이터 재생산 → 전영역 RL — 4단 파이프라인으로 R1-Zero의 가독성 문제 해결
  - **증류**: R1의 풀이 80만 개로 Qwen/Llama 1.5B~70B를 SFT만으로 — 작은 모델에 추론이 이식됨
- **RLVR**이 핵심 연료: 수학(정답 채점), 코드(테스트 실행) — 검증기가 확실한 영역부터 정복. 검증 어려운 영역(글쓰기 등)으로 확장이 현재 연구 최전선 (LLM-judge 보상, 루브릭 보상)
- **s1** (2025): 단 1,000개 샘플 SFT + "budget forcing"("Wait" 강제 삽입으로 더 생각하게) — 추론의 본질이 의외로 가볍다는 충격

### 3. Test-Time Compute — 새로운 스케일링 축
- 사전학습 스케일링(N, D) 다음의 축: **생각 토큰 수**. o1 차트가 보여준 것: RL 컴퓨트 ↑ + 생각시간 ↑ = 점수 ↑
- 직렬(더 긴 CoT) vs 병렬(n개 샘플 + 선택): best-of-n, 다수결, **PRM**(과정 보상모델)으로 단계별 채점
- 2026 연구 동향: **생각 길이의 효율** — 과잉사고(overthinking) 줄이기, 적응형 예산, 롤아웃 재활용 ([survey](https://arxiv.org/pdf/2501.02497), [agent TTC](https://arxiv.org/pdf/2506.12928))
- 하이브리드 모델이 표준: thinking on/off 또는 예산 다이얼 (Claude extended thinking, Qwen thinking 모드, Gemini thinking budget, Claude Fable 5는 "adaptive thinking 상시")

### 4. 비판적 시각 (박사라면 알아야 할 반론들)
- CoT는 "진짜 추론"인가 패턴 매칭인가 — faithfulness 연구 (모델이 쓴 풀이와 실제 내부 계산이 다를 수 있음, Phase 13)
- 벤치마크 포화·오염: AIME류 점수의 신뢰성 논쟁
- 긴 생각 = 더 많은 비용·지연. ARC-AGI 류 "비용당 지능" 곡선 보기
