> **기간**: 3주 | **선행**: 04 | **산출물**: BPE 토크나이저 from scratch + 문자단위 언어모델
>
> **건너뛰기 시험**: ① BPE 병합 과정을 손으로 시뮬레이션 ② word2vec의 학습 원리(주변 단어 예측) 설명 ③ "왕−남자+여자≈여왕"이 왜 되는지 설명 — 되면 06으로.

### 🍼 유치원 버전

**토크나이저 = 말을 레고 블록으로 쪼개는 가위야.**
- 글자 하나씩 자르면? 블록이 너무 많아져서 문장이 길어져 (느림)
- 단어째로 자르면? 세상 단어가 너무 많고, 처음 보는 단어("갓생러")는 못 잘라
- 그래서 중간: **자주 붙어 다니는 글자들을 한 블록으로** — "학교"는 자주 나오니 한 블록, "쿄뮤햣"은 글자별로
- 이게 BPE(바이트 페어 인코딩). 사실 **압축 알고리즘**이야: 자주 나오는 쌍을 새 블록으로 계속 합치기

**임베딩 = 모든 블록을 의미 지도 위 집 주소로 바꾸는 거야.**
비슷한 말은 같은 동네에 살아. "고양이"와 "강아지"는 이웃, "고양이"와 "미적분"은 다른 도시.
신기한 건 **방향에도 의미**가 있어: 왕→여왕 방향과 남자→여자 방향이 거의 평행해.
그래서 왕 − 남자 + 여자 ≈ 여왕 이라는 "단어 산수"가 돼.

## 🧠 제대로 배우기

### 1. 토큰화의 역사와 BPE
- 문자 단위 → 단어 단위(OOV 문제) → **서브워드**(1994 압축 알고리즘 BPE를 2016 NMT에 적용)
- **BPE 알고리즘** (이것만은 손으로):
  1. 텍스트를 바이트(또는 문자)로 시작
  2. 가장 자주 등장하는 인접 쌍을 찾아 새 토큰으로 병합
  3. 원하는 어휘 크기(예: 50,257)까지 반복 — 병합 규칙이 곧 토크나이저
- 실전 구현체: GPT 계열 **tiktoken**(byte-level BPE), Llama 계열 **SentencePiece**, HF tokenizers
- **한국어 이슈**: 같은 뜻이라도 한국어가 영어보다 토큰 1.5~3배 → 비용·속도·컨텍스트 불리.
  교착어(조사·어미)라 분절이 어렵고, 어휘에 한국어 비중이 작으면 글자가 잘게 쪼개짐.
  (한국어 LLM들이 토크나이저를 따로 만드는 이유)
- 토크나이저가 일으키는 유명한 버그들: "strawberry에 r 몇 개?" (글자가 안 보임 — 블록으로 보니까), 숫자 연산 약점, 띄어쓰기 민감성. **모델의 멍청함 중 상당수는 토크나이저 탓**

### 2. 임베딩 — 의미의 기하학
- 원핫 벡터의 문제: 모든 단어가 서로 직교 = "유사도 0" = 의미 없음
- **word2vec** (2013, NLP의 빅뱅): "단어의 의미는 주변 단어가 결정한다"(분포 가설)
  - Skip-gram: 중심 단어로 주변 단어 맞히기 — 이 게임만 시켰는데 의미 지도가 공짜로 생김
  - **이것이 "예측 게임 → 지능" 패턴의 첫 사례. LLM은 이 아이디어의 초거대 버전**
- 정적 임베딩의 한계: "배"(과일/선박/신체)가 한 점 → 문맥별로 달라져야 함 → 문맥 임베딩(ELMo→BERT→GPT)으로 진화
- 현대 LLM에서: 임베딩 = 첫 레이어의 lookup table (`nn.Embedding`), 학습으로 같이 배워짐

### 3. 언어모델의 역사 — 다음 토큰 예측의 진화
| 시대 | 모델 | 아이디어 | 한계 |
|---|---|---|---|
| ~2000s | n-gram | 직전 n-1개 단어 빈도표 | 길게 못 봄, 조합 폭발 |
| 2003 | 신경 LM (Bengio) | 임베딩+MLP로 다음 단어 | 고정 윈도 |
| 2014–16 | RNN/LSTM | 순서대로 읽으며 기억 상태 유지 | ① 멀수록 잊음 ② **순차 처리라 병렬화 불가** (GPU 알바 군단이 놀게 됨) |
| 2014 | seq2seq + **어텐션** (Bahdanau) | 번역 시 원문의 어느 단어를 볼지 가중치 | 어텐션은 RNN의 보조 장치였음 |
| 2017 | **트랜스포머** | "RNN 빼고 어텐션만 남기자" | → Phase 06 |

> RNN을 깊게 팔 필요는 없습니다. 하지만 "왜 버려졌나"(순차성·장기의존성)를 알아야 트랜스포머가 뭘 해결했는지 보입니다. 그리고 2024+ Mamba 같은 SSM이 "RNN의 역습"으로 부활하는 것도(Phase 10) 이 맥락에서 이해됩니다.
