# 10. 효율화와 서빙 — 같은 지능을 100배 싸게

> **기간**: 3–4주 | **선행**: 06 (KV캐시), 07 | **산출물**: vLLM 서빙 + 양자화 + QLoRA, 그리고 **M6 (nanochat 풀스택)**
>
> 연구가 "되게 만드는" 일이라면 이 장은 "감당 가능하게 만드는" 일.
> 추론(인퍼런스) 비용은 2년마다 ~10배씩 떨어져 왔고, 그 마법의 목록이 이 장입니다.

### 🍼 유치원 버전

- **양자화** = 그림을 크레파스 64색 대신 8색으로 그리기. 거의 똑같이 보이는데 가방이 확 가벼워져
- **FlashAttention** = 도서관 사서가 창고(느린 큰 메모리)와 책상(빠른 작은 메모리) 사이를 **덜 왔다갔다** 하도록 동선 짜기. 계산을 줄이는 게 아니라 **나르기를** 줄이는 거야
- **KV 캐시** = 읽던 책에 포스트잇. 안 붙이면 매번 1쪽부터 다시 읽어야 해
- **추측 디코딩** = 후배(작은 모델)가 초안을 다다다 쓰고, 선배(큰 모델)가 **한 번에** 검사. 맞으면 통과, 틀린 곳부터 다시
- **증류** = 선생님(큰 모델)의 풀이 노트를 학생(작은 모델)에게 물려주기

## 🧠 제대로 배우기

### 1. 인퍼런스는 왜 느린가 — 병목의 정체
- 토큰 생성은 한 번에 하나(자기회귀) → 매 토큰마다 **모든 가중치를 메모리에서 읽어야** 함
- 연산보다 **메모리 대역폭이 병목** (memory-bound). prefill(프롬프트 처리)은 병렬이라 compute-bound — 두 국면 구분이 모든 최적화의 출발점
- **KV 캐시 크기 손계산** (필수 암산): `2 × 층수 × KV헤드 × 헤드차원 × 토큰수 × 바이트`
  - 예: Llama-3-8B(32층, KV 8헤드, 128차원, BF16) = 토큰당 128KB → **128K 컨텍스트면 캐시만 16GB** (모델보다 큼!)
  - → GQA/MQA/MLA(06)가 왜 발명됐는지가 숫자로 보임

### 2. 커널 레벨: FlashAttention (1/2/3)
- 어텐션의 (T×T) 행렬을 HBM에 쓰지 않고 SRAM 타일 단위로 융합 계산 (online softmax)
- IO 복잡도를 낮춘 것 — **수학적으로 동일한 결과** (근사 아님!)
- FA2(병렬화 개선), FA3(Hopper 비동기+FP8) — "하드웨어를 아는 자가 이긴다"의 표본

### 3. 서빙 시스템: vLLM과 친구들
- **PagedAttention** (vLLM): KV 캐시를 OS 페이징처럼 블록 관리 → 메모리 낭비 제거
- **연속 배칭**: 끝난 요청 자리에 새 요청 즉시 투입 → GPU 놀지 않게
- **SGLang**: RadixAttention으로 공통 프리픽스 캐시 공유 (에이전트/멀티턴에 강함)
- prefill/decode 분리 서빙, prefix caching — 2026 프로덕션 표준 메뉴
- 지표 언어: TTFT(첫 토큰까지), TPOT(토큰당), throughput vs latency 트레이드오프

### 4. 양자화 — 비트를 깎는 기술
| 단계 | 기법 | 한 줄 |
|---|---|---|
| 16비트 | BF16 | 학습·서빙 기본값 |
| 8비트 | FP8(학습까지 침투, DeepSeek-V3), INT8 | 사실상 무손실 |
| 4비트 | **GPTQ**(2차 정보로 보정), **AWQ**(중요 채널 보호), **GGUF/llama.cpp**(CPU·맥북용) | 품질 손실 소폭, 메모리 1/4 |
| 그 아래 | NF4(QLoRA), FP4(차세대 HW), 1.58bit 실험 | 연구 전선 |
- 핵심 개념: outlier 문제(소수의 큰 값이 정밀도를 망침), 캘리브레이션, QAT vs PTQ
- 감각: 7B-4bit ≈ 4GB → **노트북에서 돌아감** (ollama/llama.cpp/LM Studio로 직접 확인)

### 5. 추측 디코딩 (Speculative Decoding)
- draft 모델(또는 **EAGLE**류 자체 헤드, **MTP** 헤드)이 k토큰 제안 → 본 모델이 1회 forward로 일괄 검증
- 수락률이 핵심. **분포 보존 보장** (수학적으로 본 모델과 동일한 출력 분포) — 증명 따라가볼 것
- 2–4배 속도업, 2026년 프로덕션 표준

### 6. 작은 모델 만들기: 증류·가지치기
- 지식 증류: soft label(확률 분포)로 학생 학습 — R1→Qwen 증류(09)가 대표 사례
- 가지치기/레이어 드랍, 그리고 "작은 모델 + 좋은 데이터"의 반격 (Qwen 0.6B가 5년 전 175B를 이기는 시대)

### 7. 아키텍처 레벨: 어텐션 대체 시도
- **Mamba/SSM**: RNN의 역습 — 상태 하나로 시퀀스 압축, 길이에 선형. 단독으론 회상(recall) 약함
- **하이브리드**가 현실 해법: 선형 어텐션 다수 + 풀 어텐션 소수 (Qwen3-Next, Kimi Linear, Jamba)
- 흥미로운 반례: MiniMax가 M1(하이브리드)에서 M2(풀 어텐션)로 회귀 — "아직 결판 안 남". 박사감 주제
