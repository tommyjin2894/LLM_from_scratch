> **기간**: 6개월–수년 (여기부터는 "단계"가 아니라 "생활") | **선행**: 00–13 전부
> **산출물**: **마일스톤 M7** — 논문 1편 완전 재현 + 나의 연구 질문 1개로 실험 → 워크숍 논문/기술 블로그/오픈소스 기여
>
> 박사의 정의: **"인류 지식의 경계에 아주 작은 혹 하나를 보태는 사람."**
> 지금까지가 경계까지 걸어간 길이라면, 이제 경계를 미는 법을 배웁니다.

## 🍼 유치원 버전

지금까지 너는 **요리책의 모든 요리를 따라 만들 수 있는** 요리사가 됐어.
박사는 달라: **요리책에 없는 요리를 하나 만들어서, 요리책에 한 줄을 보태는 사람**이야.
그 한 줄은 아주 작아도 돼. "설탕 대신 꿀을 넣으면 이런 경우에 더 맛있다" 정도면 충분해.
대신 **진짜여야 해** — 다른 요리사가 따라 했을 때 똑같이 되어야 하고(재현), 왜 그런지 설명돼야 해(ablation).

## 1. 논문 읽기 — 박사의 주식(主食)

### 3-pass 읽기법 (Keshav)
1. **1차 (5분)**: 제목·초록·그림·결론만 — "내가 더 읽어야 하나?" 판단. 논문의 90%는 여기서 끝
2. **2차 (30분)**: 본문 통독, 수식은 건너뛰며 — 핵심 주장과 증거 파악. 주당 5–10편은 이 수준
3. **3차 (2–4시간)**: 재구현 가능 수준으로 — "내가 저자라면 어떻게 했을까"를 먼저 생각하고 대조. 주당 1편

### 비판적 읽기 체크리스트 (13에서 배운 것 총동원)
- 베이스라인이 공정한가? (튜닝 덜 된 베이스라인 = 흔한 반칙)
- 비교가 같은 컴퓨트/데이터인가? ablation이 주장을 실제로 지지하는가?
- 점수 차이가 노이즈 범위 밖인가? 오염 가능성은? 코드·체크포인트 공개?
- "왜 됐는가"에 대한 설명이 있는가, 아니면 점수 자랑뿐인가?

### 흐름 따라가기 루틴 (주 3–4시간)
- 매일: arXiv cs.CL/cs.LG 신착 훑기 (alphaxiv/HF Daily Papers 큐레이션 활용)
- 매주: 뉴스레터 — Interconnects(Nathan Lambert, 정렬/RL 최고), Ahead of AI(Raschka, 구현 관점), AI News(전체 요약)
- 매분기: 프런티어 테크리포트 정독 (DeepSeek/Qwen/Llama류는 전문 공개 — 공짜 대학원 수업)
- 학회 캘린더: ICLR/ICML/NeurIPS(ML 종합), ACL/EMNLP(NLP), **COLM**(LM 전문, 2024 신설) — 박사과정이면 여기 투고

## 2. 재현 — 첫 연구는 남의 논문 다시 만들기

> 재현은 "베끼기"가 아니라 **가장 빠른 연구 훈련**입니다. 논문이 숨긴 디테일(학습률! 데이터 전처리!)을
> 전부 직접 결정해봐야 논문 행간이 읽힙니다. open-r1, TinyZero, nanoGPT 전부 재현 프로젝트로 시작했습니다.

추천 재현 사다리 (M7 후보):
1. (이미 함) GPT-2 재현 (M3), TinyZero/R1 재현 (M5)
2. DPO vs SimPO vs ORPO를 같은 조건에서 공정 비교 — 논문들 주장이 서로 충돌하는 지점 직접 판정
3. 스케일링 법칙 미니 재현: 10M~200M 모델 5개로 멱법칙 피팅
4. SAE 학습 재현 (작은 모델 1개 층) + 피처 보고서
5. 최신 화제 논문 중 "코드 미공개 + 주장 강함" 하나 골라 검증 — 그 자체로 가치 있는 기여

## 3. 연구 질문 찾기 — 2026년 열린 문제 지도

> 좋은 질문의 조건: ① 궁금해서 잠이 안 옴 ② 작은 스케일에서 신호를 볼 수 있음 ③ 결과가 yes든 no든 배울 게 있음

### A. 데이터와 학습
- 고품질 데이터 고갈: 합성 데이터의 한계는? 모델 붕괴는 실제로 언제 오나?
- 커리큘럼/데이터 순서 효과는 왜 있는가 (annealing의 과학)
- **지속 학습(continual learning)**: 새 지식을 까먹지 않고 추가하는 법 — 미해결의 왕
- 작은 모델의 한계: 1B로 어디까지? (증류+RL+데이터의 합성 한계 탐구)

### B. 추론과 RL
- test-time compute **효율**: 과잉사고 억제, 적응형 사고 예산, 롤아웃 재활용 (2026 최핫 — [survey](https://arxiv.org/pdf/2501.02497))
- 검증 불가능 영역(글쓰기·연구·디자인)의 보상 설계 — 루브릭? judge? 과정보상?
- RL 스케일링 법칙: 사전학습의 Chinchilla 같은 법칙이 RL에도 있나?
- 자기개선 루프: 모델이 만든 데이터로 모델 개선 — 어디서 멈추나?

### C. 아키텍처
- 어텐션 너머: 하이브리드 선형 어텐션의 회상(recall) 한계 정량화 (MiniMax의 회귀는 왜?)
- 디퓨전 LM vs 자기회귀: 병렬 생성의 진짜 트레이드오프
- 길이 일반화: 학습보다 긴 문맥에서의 체계적 실패 원인
- 진짜 장기 메모리: 컨텍스트가 아닌 가중치/외부 상태로의 기억 통합

### D. 에이전트
- 오류 누적 극복: 자기 검증·복구의 학습 (0.95²⁰ 문제)
- 프롬프트 인젝션의 구조적 해결 (권한 분리 아키텍처)
- 멀티에이전트 협업의 스케일링: 언제 1+1>2인가
- 장기 과제 평가론: METR식 "시간 지평" 측정의 정교화

### E. 해석·안전·과학
- SAE 피처의 인과적 검증: 상관 피처 vs 진짜 회로
- CoT 충실성: 추론 모델 감시가능성은 유지되는가 (process 감시 vs 결과 감시)
- 환각의 근본 원인: 보정(calibration)과 "모른다고 말하기"의 학습 역학
- 창발의 과학: 능력은 정말 불연속인가, 측정의 착시인가
- LLM의 과학적 이해 자체 (왜 in-context learning이 되는가 — 아직도 미답)

## 4. 연구 실행 — 아이디어를 증거로

```
가설 (반증 가능하게 한 문장) → 최소 실험 설계 (가장 작은 스케일로 신호 확인)
→ 베이스라인 먼저 (남의 방법을 최선으로) → 내 방법 → ablation (뭘 빼면 무너지나)
→ 스케일 확인 (작은 데서 된 게 큰 데서도?) → 글쓰기 (사실은 처음부터 같이)
```
- 연구 코드 규율: 실험=커밋 1개, config 파일화, 시드 3개, wandb 태그 — "그때 그 숫자 어떻게 나왔지?"를 박멸
- 컴퓨트 현실: 학계는 GPU 빈곤 → **작은 스케일 프록시 설계 능력**이 곧 연구 경쟁력 (TinyStories, NanoGPT speedrun, 0.6B대 RL이 다 그 산물)
- 글쓰기: 그림 1이 논문의 절반. "기여 3줄"을 먼저 쓰고 실험을 거기 맞춰 정렬
