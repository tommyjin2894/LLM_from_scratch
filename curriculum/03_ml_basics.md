# 03. 머신러닝 기초 — "학습"이라는 게 정확히 뭐야?

> **기간**: 2–3주 | **선행**: 01, 02 | **산출물**: 라이브러리 없이 경사하강법으로 분류기 학습
>
> **건너뛰기 시험**: ① 과적합을 train/val 곡선으로 설명 ② 로지스틱 회귀 손실(로그 손실)을 MLE에서 유도 ③ 편향-분산 트레이드오프 설명 — 되면 04로.

### 🍼 유치원 버전

**학습 = 강아지 훈련이야.**
- "앉아" 했는데 앉으면 간식(낮은 손실), 안 앉으면 간식 없음(높은 손실)
- 강아지는 간식을 더 받는 쪽으로 행동을 조금씩 바꿔 (경사하강법)
- 그런데! 우리 집 거실에서만 훈련하면, 공원에 나가서는 말을 안 들어 (**과적합**)
- 그래서 가끔 공원에서 시험을 봐야 해 (**검증 데이터**)

**과적합을 한 번 더**: 기출문제 답만 통째로 외운 학생은 모의고사(기출) 100점, 수능(새 문제) 빵점.
**일반화**란 "외우기"가 아니라 "원리 익히기". LLM의 평생 숙제도 이것.

## 🧠 제대로 배우기

### 1. 학습의 3요소 — 모든 ML은 이 틀
| 요소 | 뜻 | LLM에서는 |
|---|---|---|
| 모델(가설 공간) | 입력→출력 함수의 후보들 | 트랜스포머 (파라미터가 정해지면 함수 하나) |
| 손실함수 | "얼마나 틀렸나" 측정기 | 크로스 엔트로피 (01에서 배움!) |
| 최적화 | 손실 줄이는 파라미터 찾기 | AdamW + 경사하강 |

### 2. 패러다임 3종
- **지도학습**: 문제+정답 쌍으로 배움 → SFT가 이것
- **비지도/자기지도학습**: 정답 라벨 없이 데이터 자체에서 배움 → **사전학습이 이것** (다음 토큰이 곧 정답이라 라벨 공짜!)
- **강화학습**: 행동→보상으로 배움 → RLHF/GRPO가 이것
> LLM 파이프라인은 사실 세 패러다임의 릴레이입니다. 03에서 큰 그림만 잡고 각각 07/08/09에서 깊게.

### 3. 핵심 알고리즘 (직접 구현할 것)
- **선형회귀**: 가장 단순한 "다이얼 맞추기". 닫힌해 vs 경사하강 비교
- **로지스틱 회귀**: 시그모이드로 확률 출력 + 로그손실. **사실상 1층 신경망.**
  유도 포인트: 베르누이 MLE → 로그손실 (01의 "MLE=크로스엔트로피"가 여기서 재등장)
- **소프트맥스 회귀**: 다중 클래스 → LLM의 출력층(다음 토큰 분류기 = 클래스가 어휘 수만큼 있는 소프트맥스 회귀!)

### 4. 일반화 도구상자
| 개념 | 한 줄 | 실무 감각 |
|---|---|---|
| train/val/test 분할 | 공부용/모의고사/수능 | test는 마지막에 딱 한 번 |
| 과적합/과소적합 | 외움/덜 배움 | train↓ val↑ 벌어지면 과적합 |
| 정규화(regularization) | 외우기 방해 장치 | weight decay, 드롭아웃(04) |
| 편향-분산 | 단순해서 틀림 vs 예민해서 틀림 | 모델 크기 선택의 언어 |
| 하이퍼파라미터 | 사람이 정하는 다이얼 | 학습률이 왕. 항상 학습률부터 의심 |
| 데이터 누수(leakage) | 시험지 유출 | LLM 벤치마크 오염 문제의 원형 (13에서 재등장) |

### 5. (개념만) 고전 ML 둘러보기
kNN, 결정트리, SVM, k-means — 면접/논문에 가끔 나오니 "그게 뭔지" 수준만. 깊게 파지 말 것. 우리 목적지는 딥러닝.
