# 11. 멀티모달 — 눈과 귀를 다는 법

> **기간**: 2–3주 | **선행**: 06–08 | **산출물**: VLM 아키텍처 해부 노트 + 미니 실험
>
> 2026년 프런티어 모델은 전부 멀티모달입니다 (GPT-5.5, Gemini 3.x, Claude, MiniMax M3...).
> 다행히 핵심 아이디어는 하나로 수렴했습니다: **"모든 것을 토큰으로 만들어 같은 트랜스포머에 넣는다."**

### 🍼 유치원 버전

LLM은 레고 블록(토큰)만 먹는 기계야. 그럼 사진은 어떻게 먹이지?
**사진을 퍼즐 조각으로 잘라서, 조각마다 레고 블록으로 바꿔주면 돼!**
- 사진 → 16×16 픽셀 조각들 (패치) → 각 조각을 벡터로 (ViT)
- 그 벡터들을 글자 토큰들 사이에 끼워 넣어: "다음 [🧩][🧩][🧩]...[🧩] 사진을 설명해줘"
- LLM 입장에선 그냥 "외국어 단어가 좀 섞인 문장"이야. 어텐션은 똑같이 작동해

귀(오디오)도 마찬가지: 소리 → 작은 조각 → 토큰. **만물 토큰화**가 멀티모달의 전부야.

---

## 🧠 제대로 배우기

### 1. ViT — 이미지의 트랜스포머화 (2020)
- 이미지를 16×16 패치로 → 각 패치를 선형 투영 → 토큰 시퀀스로 취급 → 표준 트랜스포머
- CNN의 귀납 편향(지역성) 없이도 데이터가 크면 승리 — "스케일이 구조를 이긴다"의 비전판

### 2. CLIP — 이미지와 텍스트를 같은 지도에 (2021, 멀티모달의 주춧돌)
- (이미지, 캡션) 4억 쌍으로 **대조학습(contrastive)**: 맞는 쌍은 가깝게, 틀린 쌍은 멀게
- 결과: "고양이 사진"과 "cat"이라는 글자가 **같은 의미 공간의 이웃**이 됨
- 부산물: zero-shot 분류, 그리고 모든 VLM의 비전 인코더 (SigLIP 등 후속)

### 3. VLM 표준 레시피 — LLaVA 패턴 (2023~현재)
```
이미지 → [비전 인코더 (CLIP/SigLIP-ViT)] → 패치 벡터들
        → [프로젝터 (MLP)] → LLM 임베딩 공간으로 번역
        → [LLM] ← 텍스트 토큰과 함께 어텐션
```
- 학습: ① 프로젝터만 정렬 학습 → ② 비전+LLM 함께 지시 튜닝 (단계적 해동)
- 이 단순한 레시피가 Qwen-VL, InternVL 등 오픈 VLM 전부의 골격
- 디테일 이슈: 해상도 처리(타일링/AnyRes), 패치 토큰 수 압축, OCR·차트·비디오(=프레임 시퀀스)

### 4. 네이티브 멀티모달 — 처음부터 같이 (2024~)
- 후부착(LLaVA) vs **네이티브**(사전학습부터 텍스트+이미지+오디오 혼합): GPT-4o, Gemini 계열
- 통합 토크나이저 접근: 이미지를 이산 토큰으로 (VQ-VAE 계열) → **생성까지 같은 자기회귀로** (GPT-4o 이미지 생성)
- 실시간 음성: 오디오 토큰 스트리밍 (음성↔음성 직접, STT/TTS 파이프라인 제거)

### 5. 이미지 "생성"은 다른 가문 — 디퓨전 (개념만)
- 🍼 *노이즈 구름에서 조각을 깎아내듯, "조금 덜 노이즈"를 반복해 그림 완성*
- Stable Diffusion/DALL-E류: 별도 계보 (이 커리큘럼 범위 밖, 교양으로)
- 단, **디퓨전 언어모델**(LLaDA, Mercury, Gemini Diffusion 실험)은 텍스트 생성의 대안 패러다임으로 주목 — 박사감 주제

### 6. 2026 동향
- 오픈도 네이티브 멀티모달로: MiniMax M3 (1M ctx + 멀티모달), Qwen-VL/Omni 라인
- 비디오 이해 표준화 (Gemini 3.x), 컴퓨터 화면 이해 = 에이전트의 눈 (Phase 12와 직결)
- world model 방향: 비디오 생성+물리 이해 (Genie류) — 연구 최전선

1. **[필수]** CLIP zero-shot 분류 실험: 내 사진 20장, 프롬프트(클래스 문장) 바꿔가며 정확도 변화 관찰

3. **[심화]** 미니 프로젝터 학습: 동결된 SigLIP + 동결된 0.6B LLM 사이 MLP만 캡션 데이터로 학습 → 그럴듯한 캡션이 나오는 최소 실험
4. **[심화]** 같은 이미지 질문을 텍스트 OCR 경유 vs VLM 직접 — 차트/표에서 성능 비교
