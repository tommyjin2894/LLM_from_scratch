# 📖 용어집 — 유치원 버전 + 정확한 정의

> 형식: **용어** — 🍼 유치원 버전 / 🎓 정확한 정의

## 기본 재료
- **토큰(token)** — 🍼 말 레고 블록 / 🎓 토크나이저가 정의한 텍스트 최소 단위 (보통 서브워드, ~0.7 단어)
- **토크나이저** — 🍼 문장을 블록으로 자르는 가위 / 🎓 텍스트↔토큰ID 변환기 (BPE 등 압축 기반)
- **임베딩** — 🍼 단어의 의미 지도 주소 / 🎓 이산 토큰의 연속 벡터 표현
- **파라미터(가중치)** — 🍼 뇌 속 다이얼 / 🎓 학습으로 조정되는 행렬 원소들
- **컨텍스트 윈도** — 🍼 한 번에 기억 가능한 분량 / 🎓 1회 forward에 처리하는 최대 토큰 수
- **로짓(logit)** — 🍼 소프트맥스 들어가기 전 점수 / 🎓 정규화 전 클래스별 실수 점수
- **온도(temperature)** — 🍼 모험심 다이얼 / 🎓 로짓을 T로 나눠 분포 평탄/뾰족 조절
- **top-p (nucleus)** — 🍼 상위 후보만 뽑기 통 / 🎓 누적확률 p까지의 후보 집합에서만 샘플링

## 학습
- **손실(loss)** — 🍼 틀린 정도 점수 / 🎓 모델 출력과 목표의 차이를 재는 스칼라 함수
- **크로스 엔트로피** — 🍼 "정답에 준 확률이 낮을수록 벌점" / 🎓 −Σ p log q. LM 사전학습 손실
- **퍼플렉시티(PPL)** — 🍼 헷갈림 지수 (평균 몇 개 사이 고민?) / 🎓 exp(평균 CE)
- **경사하강법** — 🍼 안개 산 내려가기 / 🎓 손실 그래디언트 반대 방향 파라미터 갱신
- **역전파** — 🍼 "누구 탓이야" 거꾸로 따지기 / 🎓 연쇄법칙 기반 그래디언트 효율 계산
- **학습률** — 🍼 한 걸음 크기 / 🎓 갱신 스텝 크기 (warmup+cosine이 LLM 표준)
- **배치** — 🍼 한 번에 채점하는 시험지 묶음 / 🎓 1회 갱신에 쓰는 샘플 수
- **에폭** — 🍼 교과서 1회독 / 🎓 데이터 전체 1회 통과 (LLM 사전학습은 ~1 에폭)
- **과적합** — 🍼 기출 답안 통째 외우기 / 🎓 학습 데이터 특이성까지 학습해 일반화 실패
- **체크포인트** — 🍼 게임 세이브 / 🎓 파라미터+옵티마이저 상태 저장본

## 아키텍처
- **트랜스포머** — 🍼 어텐션으로 만든 레고 성 / 🎓 어텐션+FFN 블록의 적층 시퀀스 모델
- **어텐션** — 🍼 누구 말을 얼마나 들을까 / 🎓 Q·K 유사도로 V를 가중합하는 연산
- **Q/K/V** — 🍼 찾는 쪽지/명함/실제 내용 / 🎓 입력의 세 가지 선형 투영
- **멀티헤드** — 🍼 안경 여러 개로 동시에 보기 / 🎓 차원 분할 후 병렬 어텐션, concat
- **causal mask** — 🍼 뒷장 컨닝 금지 / 🎓 미래 위치 점수를 −∞ 처리
- **FFN/MLP** — 🍼 모은 정보 혼자 소화하기 / 🎓 토큰별 2층 비선형 변환 (SwiGLU 표준)
- **잔차 연결** — 🍼 고속도로 본선 + 옆길 / 🎓 x+f(x), 그래디언트 직통로
- **RMSNorm** — 🍼 신호 크기 리셋 / 🎓 평균 제거 없이 RMS로 정규화
- **RoPE** — 🍼 단어마다 시계바늘 돌리기 / 🎓 위치 비례 회전으로 상대위치를 내적에 인코딩
- **KV 캐시** — 🍼 읽은 데 포스트잇 / 🎓 생성 시 과거 K,V 재계산 방지 저장소
- **GQA / MLA** — 🍼 명함 공유 / 요약본만 보관 / 🎓 KV 헤드 공유 / KV 저랭크 잠재 압축
- **MoE** — 🍼 접수처가 전문의 몇 명에게만 보내는 병원 / 🎓 라우터가 토큰별 일부 전문가 FFN만 활성화
- **활성 파라미터** — 🍼 출근한 의사 수 / 🎓 토큰 1개 처리에 실제 사용되는 파라미터
- **MTP** — 🍼 다음 한 칸 말고 두세 칸 내다보기 / 🎓 다중 미래 토큰 예측 보조 목표

## 파이프라인
- **사전학습** — 🍼 도서관 통째로 읽기 / 🎓 대규모 코퍼스 다음 토큰 예측 (자기지도)
- **베이스 모델** — 🍼 아는 건 많은데 대화 못 하는 친구 / 🎓 정렬 전 사전학습 모델
- **SFT** — 🍼 모범답안 따라쓰기 / 🎓 (지시,응답) 쌍 지도 파인튜닝
- **RLHF** — 🍼 칭찬 스티커 학습 / 🎓 인간 선호 보상모델 + RL(주로 PPO)로 정책 최적화
- **보상모델(RM)** — 🍼 채점 로봇 / 🎓 선호 쌍으로 학습한 응답 점수 함수
- **KL 페널티** — 🍼 "원래 너에서 멀어지지 마" 목줄 / 🎓 참조 정책과의 발산 벌점
- **DPO** — 🍼 채점 로봇 없이 좋은 답 동그라미 / 🎓 선호쌍으로 암묵 보상 직접 최적화
- **GRPO** — 🍼 반평균보다 잘한 풀이 따라하기 / 🎓 그룹 상대 advantage로 critic 없는 정책경사
- **RLVR** — 🍼 채점기가 진짜인 시험 (정답/테스트) / 🎓 검증 가능 보상 기반 RL
- **보상 해킹** — 🍼 채점 로봇 속이기 / 🎓 진짜 목표 대신 보상 함수의 빈틈 최적화
- **정렬(alignment)** — 🍼 지니가 소원의 '의도'를 알아듣게 하기 / 🎓 모델 행동을 인간 의도·가치에 맞추는 문제
- **증류** — 🍼 선생님 풀이노트 물려주기 / 🎓 큰 모델 출력으로 작은 모델 학습
- **LoRA** — 🍼 본체 그대로, 보조 다이얼만 / 🎓 ΔW=BA 저랭크 어댑터 학습

## 추론(리즈닝)과 인퍼런스
- **CoT** — 🍼 연습장에 풀이 쓰기 / 🎓 최종 답 전 중간 추론 토큰 생성
- **test-time compute** — 🍼 시험시간 더 사기 / 🎓 인퍼런스 시 계산량 증가로 성능 스케일링
- **thinking 모드** — 🍼 곰곰이 모드 스위치 / 🎓 추론 토큰 생성 on/off 또는 예산 제어
- **prefill / decode** — 🍼 문제 읽기 / 답안 쓰기 / 🎓 프롬프트 병렬 처리 국면 / 토큰 순차 생성 국면
- **추측 디코딩** — 🍼 후배 초안 + 선배 일괄 검사 / 🎓 draft 제안을 본 모델이 병렬 검증 (분포 보존)
- **양자화** — 🍼 크레파스 64색→8색 / 🎓 가중치/활성값 저비트 표현 (INT8/FP8/4bit)
- **FlashAttention** — 🍼 사서의 동선 최적화 / 🎓 SRAM 타일링으로 IO 최소화한 정확한 어텐션
- **TTFT/TPOT** — 🍼 첫마디까지 / 말 한마디당 시간 / 🎓 서빙 지연 지표

## 평가·안전·해석
- **벤치마크** — 🍼 모의고사 / 🎓 표준화된 능력 측정 과제 집합
- **오염(contamination)** — 🍼 기출 유출 / 🎓 평가 데이터가 학습 데이터에 포함
- **굿하트의 법칙** — 🍼 점수가 목표가 되면 점수가 거짓말함 / 🎓 지표 최적화가 본래 목표와 괴리
- **환각** — 🍼 자신만만 허풍 / 🎓 비사실 내용의 유창한 생성
- **탈옥(jailbreak)** — 🍼 말로 꼬셔서 규칙 어기게 하기 / 🎓 안전학습 우회 입력
- **프롬프트 인젝션** — 🍼 읽을거리 속에 숨긴 가짜 명령 / 🎓 데이터 채널로 주입된 지시 실행 취약점
- **LLM-as-judge** — 🍼 AI가 AI 채점 / 🎓 모델 기반 자동 평가 (편향 주의)
- **superposition** — 🍼 서랍 하나에 물건 여러 개 / 🎓 뉴런 수보다 많은 피처의 중첩 표현
- **SAE** — 🍼 뒤섞인 서랍을 정리하는 기계 / 🎓 활성값을 희소 피처로 분해하는 오토인코더
- **창발(emergence)** — 🍼 어느 날 갑자기 되는 것(처럼 보이는 것) / 🎓 스케일 증가 시 비연속적으로 보이는 능력 출현 (측정 착시 논쟁 有)
- **in-context learning** — 🍼 예시 몇 개 보고 바로 따라하기 / 🎓 가중치 갱신 없이 프롬프트 예시로 태스크 수행
